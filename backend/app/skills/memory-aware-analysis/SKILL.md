# Memory-Aware Analysis

When performing:
- strategic reviews
- outlook analysis
- investment analysis
- trend analysis
- risk assessments
- executive reviews

Follow this process:

1. Retrieve previous conclusions using `research_memory_tool`.

2. Retrieve current evidence using document retrieval tools.

3. Compare previous conclusions against current evidence.

4. Identify:
   - What remains true
   - What has changed
   - New risks
   - Reduced risks
   - Increased confidence
   - Reduced confidence

5. Produce:

## Previous Conclusion

## New Evidence

## Changes Since Previous Research

## Updated Assessment

## Confidence Level

## Final Conclusion

Do not simply repeat previous memory.
Use it as a baseline for evaluating change.
