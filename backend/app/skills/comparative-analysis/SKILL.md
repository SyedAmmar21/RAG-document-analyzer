# Comparative Analysis Skill

When a user asks to:

- compare documents
- identify contradictions
- identify agreements
- find trends
- analyze multiple perspectives

Follow this process:

1. Gather evidence from retrieved documents.
2. Group evidence by source.
3. Identify agreements.
4. Identify disagreements.
5. Identify implications.
6. Produce a structured comparison.
7. Cite all sources used.
